# Bootstrap Evaluation

### Claim

初始化能够确定性地建立固定骨架，保留已有项目内容；协议差异得到准确分类，替换仅通过明确选择执行，并保留可恢复的原文件。独立分发的 Skill 不依赖 MukiDoc 源仓库。

### Scope

覆盖本地文件初始化、版本比较、备份与替换、资源包完整性和独立脚本运行。不验证旧文档迁移、真实业务运行，也不把程序参数测试当成 Agent 在对话中正确询问用户的证据。

### Method

在隔离的临时项目运行真实命令，比较操作前后完整文件内容，检查固定目录、骨架文档和未创建的可选项。构造旧版、同版修改、无版本和更高版本协议，覆盖默认保留与显式替换。复制整个 Skill 到独立位置再次执行。资源导出一致性和 Skill 结构单独检查。

### Oracle

1. 新项目具备完整固定骨架，无可选空文档或 MukiCheck；AGENTS.md 与内置协议字节一致。
2. 重复执行不修改既有文件，包括用户正文和空文档；缺失骨架能补齐。
3. 默认不覆盖已有协议，版本与内容状态区分正确；拒绝未来版本降级。
4. 显式更新保留完整旧文件备份，其他文档不变；原文件在审查后改变时拒绝替换。
5. 预览不写入；路径冲突和损坏资源包在写入前报错，不能沿受管符号链接写入其他位置。
6. 独立 Skill 目录能够执行初始化，不读取源仓库的运行依赖。

### 本轮证据

2026-09-25，Skill 0.1.0 / 协议 0.1.0 在本机临时目录运行 `python3 -B -m unittest discover -s tests -v`，18 项测试全部通过。覆盖首次与重复初始化、部分既有项目、预览不写入、六种协议状态、数字版本比较、备份替换、过期内容指纹、拒绝降级、路径类型冲突、受管符号链接、资源损坏及独立 Skill 副本运行。已有文件按字节与修改时间检查保留；备份按字节比较。

`scripts/sync_skill_assets.py --check` 已通过，根协议与打包协议及全部模板校验值一致。Skill Creator 的 `quick_validate.py` 已通过；本机默认 Python 缺少该校验器依赖的 PyYAML，使用临时 uv 环境运行校验器，初始化脚本本身仍仅使用标准库。

Skill 在真实对话中发现旧协议、展示实际差异并等待用户选择的行为仍待独立验证。本轮没有安装个人 Skill、修改外部项目或执行文档迁移。
